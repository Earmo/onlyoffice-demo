# Plan 03-01: 设计用户上下文抽象与接入契约

## Outcome

先把“怎么解析用户上下文”这件事做成稳定契约：建立 `AccessContext`、provider SPI、内置 header/jwt/default provider、可配置顺序和严格错误语义，为后续 editor 与文档 API 接线打地基。
