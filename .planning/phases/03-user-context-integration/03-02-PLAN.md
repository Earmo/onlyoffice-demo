# Plan 03-02: 把用户上下文接入编辑配置和文档操作

## Outcome

在不引入完整权限平台的前提下，把新的访问上下文真正接入 editor config、创建/上传/导入、列表/详情这些主路径，并让最小 permissions map 开始影响编辑器行为。
