# Plan 05-02: 收口 ONLYOFFICE 分布式配置、下载与 callback 闭环

## Outcome

把“ONLYOFFICE 和当前服务之间到底怎么彼此信任、怎么拿对 URL”这件事做扎实：正式接通 callback JWT 验签，统一收口 `document.url` / `callbackUrl` / `documentServerUrl` 的角色化生成，并对坏配置尽早失败。
