# Plan 09-02: 增加预览模式并重构编辑工作台布局

## Outcome

把当前“只有编辑页”的工作流升级成“预览页 + 编辑页”双入口，同时把编辑页从抽屉遮罩式控制台改造成固定同层工作台布局，让页面结构真正服务于长期使用。
