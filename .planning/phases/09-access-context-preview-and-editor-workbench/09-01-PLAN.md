# Plan 09-01: 收口访问上下文策略与扩展契约

## Outcome

把当前已经存在的 `AccessContextProvider` SPI 正式提升为稳定的访问上下文策略体系：内置 `header` / `jwt` 两类显式解析策略，保留 `default` 作为补齐兜底策略，并明确自定义策略的注册、优先级和错误语义。
