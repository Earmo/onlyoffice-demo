# Plan 07-01: 创建后端多模块骨架与构建边界

## Outcome

把当前单 jar 后端改成父聚合工程 + data 模块 + service 模块，为后续 repository 重构和 starter 命名收敛提供稳定落点。

## Tasks

<task id="7-01-01">
  <read_first>
    <file>packages/server/pom.xml</file>
    <file>packages/server/Dockerfile</file>
    <file>.planning/phases/07-module-boundaries-and-repository-refactor/07-RESEARCH.md</file>
    <file>.planning/ROADMAP.md</file>
  </read_first>
  <action>
    将 `packages/server/pom.xml` 从当前单模块 `jar` 工程改成父聚合 POM，明确设置 `<packaging>pom</packaging>`，并在 `<modules>` 中声明 `onlyoffice-integration-data` 与 `onlyoffice-integration-service` 两个子模块。
    新建 `packages/server/onlyoffice-integration-data/pom.xml` 和 `packages/server/onlyoffice-integration-service/pom.xml`：
    data 模块只保留数据库、Flyway、MyBatis-Flex、Lombok 等通用依赖，不配置 `spring-boot-maven-plugin`；
    service 模块声明对 data 模块的显式依赖，并保留 `spring-boot-starter-web`、Knife4j、JWT、boot 插件等运行时依赖。
    父 POM 统一维护 `groupId`、`version`、`java.version`、Spring Boot 版本和依赖管理，避免子模块各自分叉版本。
  </action>
  <verify>`cd packages/server && mvn -q -DskipITs test`</verify>
  <acceptance_criteria>
    <criterion>`packages/server/pom.xml` contains `<packaging>pom</packaging>`</criterion>
    <criterion>`packages/server/pom.xml` contains `<module>onlyoffice-integration-data</module>`</criterion>
    <criterion>`packages/server/pom.xml` contains `<module>onlyoffice-integration-service</module>`</criterion>
    <criterion>`packages/server/onlyoffice-integration-data/pom.xml` exists</criterion>
    <criterion>`packages/server/onlyoffice-integration-service/pom.xml` exists</criterion>
    <criterion>`packages/server/onlyoffice-integration-data/pom.xml` does not contain `spring-boot-maven-plugin`</criterion>
    <criterion>`packages/server/onlyoffice-integration-service/pom.xml` contains `spring-boot-maven-plugin`</criterion>
  </acceptance_criteria>
  <done>后端 Maven 反应堆结构建立完成，service/data 模块职责边界已显式存在。</done>
</task>
