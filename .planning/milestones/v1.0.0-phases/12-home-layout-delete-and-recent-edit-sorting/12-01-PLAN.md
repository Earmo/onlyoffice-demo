# Plan 12-01: 后端逻辑删除、最近编辑排序与可见性契约

## Outcome

把“删除一份文档”从一个尚未落地的状态枚举值，收口成真正可消费的后端合同：主列表、最近文档和标准运行时入口都遵守同一套可见性与最近编辑排序规则。

    1. 在 `DocumentMetadataRepository` 中新增明确的“仅返回活跃文档”的查询路径，默认排除 `status = archived` 的记录，不允许用户侧默认列表继续把归档文档混进来；

    5. `DocumentMetadataRepositoryTest` 和 `DocumentApiControllerTest` 需要覆盖：
       - 归档文档默认不出现在列表 / 最近文档结果里
       - 默认结果按最近编辑时间倒序
       - 响应体包含 `lastEditedTime`
