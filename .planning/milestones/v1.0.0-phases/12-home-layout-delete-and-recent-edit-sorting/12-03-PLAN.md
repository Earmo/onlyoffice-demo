# Plan 12-03: 最近文档真相源、删除操作接线与回归测试

## Outcome

把首页真正接上 Phase 12 的新后端合同：最近文档不再是当前页切片，删除动作会刷新两侧数据，用户看到的列表顺序和最近文档都以最近编辑时间的服务端真相为准。
