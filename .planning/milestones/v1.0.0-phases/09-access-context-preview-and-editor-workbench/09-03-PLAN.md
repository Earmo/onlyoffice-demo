# Plan 09-03: 增加编辑会话结束与列表状态收敛

## Outcome

为编辑页补上显式会话生命周期，让“进入编辑器”“离开编辑器”“切换文档”成为可追踪、可收口的业务动作，并让列表上的“编辑中”真正反映当前是否还有活跃编辑用户。

## Notes for Execution

- 运行事件流继续负责“发生过什么”，活跃会话负责“现在是否有人在编辑”，这两个概念不要混用。
- 列表页的收敛目标是“状态正确”，不是把编辑页的所有运行态细节搬回首页。
