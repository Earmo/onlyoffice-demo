# Plan 11-03: 编辑退出状态收敛与回归加固

## Outcome

把“离开编辑页”从一个容易竞态的 UI 动作，收口成一次明确的退出编排：停止运行态、结束会话、刷新列表真相源，并用前后端回归测试把这个链路锁住。
