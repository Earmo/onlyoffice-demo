# Plan 11-01: 后端 ULID 文档主键与标题解耦

## Outcome

把“内部主键是谁”和“用户看到的标题是什么”这两个概念彻底分开：`documentId` 只承担服务内部稳定标识，`title` 与 `externalDocumentId` 分别承担展示与上游映射语义。
