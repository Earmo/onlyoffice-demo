## Notes for Execution

- COS 是在现有 provider-neutral 抽象上扩容，不要把厂商 SDK 细节暴露到 controller、service 或返回模型中。
- 如果 COS 测试无法依赖真实云环境，优先使用可验证的 SDK mock 或本地替身，但测试语义必须覆盖异常转换和读写闭环。
