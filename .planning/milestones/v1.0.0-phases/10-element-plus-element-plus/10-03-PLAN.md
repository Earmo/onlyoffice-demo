# 10-03. Component Level Refactor

## Objective
Refactor specific, interactive components into their Element Plus equivalents (`el-table`, `el-button`, `el-tag`, `el-dialog`).

## Requirements
- `DocumentList.vue` replaces structural divs with `el-table`.
- Statuses in the table should use `el-tag` components.
- Buttons should map visually: Primary CTA gets `type="primary"`, Destructive gets `type="danger"`.
- Modals or confirm prompts should use `el-dialog` or `ElMessageBox`.
