# 10-01. Base Infrastructure & Library Setup

## Objective
Configure the Vue 3 frontend project (`packages/web`) to auto-import Element Plus components and its stylesheet, while stripping out obsolete custom layout CSS.

## Requirements
- Element Plus and its official icon library are correctly added to deps.
- Auto import plugins (`unplugin-vue-components` and `unplugin-auto-import`) are configured.
- Minimal CSS resets are kept; the rest of the custom styling is cleaned up so Element can take over.

## Tasks

<task>
<action>
Modify `packages/web/package.json`. Add the following to `dependencies`:
- `"element-plus": "^2.6.0"`
- `"@element-plus/icons-vue": "^2.3.1"`

Add the following to `devDependencies`:
- `"unplugin-vue-components": "^0.26.0"`
- `"unplugin-auto-import": "^0.17.5"`
</action>

<task>
<action>
Modify `packages/web/vite.config.js`. You must import AutoImport and Components from unplugin-auto-import/vite and unplugin-vue-components/vite respectively, and ElementPlusResolver from unplugin-vue-components/resolvers. 
Add them to the Vite `plugins` array:
```javascript
AutoImport({ resolvers: [ElementPlusResolver()] }),
Components({ resolvers: [ElementPlusResolver()] }),
```
