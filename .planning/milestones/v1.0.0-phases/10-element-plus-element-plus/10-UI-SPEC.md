## Design System

| Property | Value |
|----------|-------|

| Font | var(--el-font-family) |

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing and table cell padding |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps for EditorWorkbench |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: Element default sizes (`size="small"`, `size="default"`, `size="large"`) will be used.

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 | 1.5 |
| Label | 12px | 500 | 1.5 |
| Heading | 18px | 600 | 1.5 |
| Display | 24px | 700 | 1.2 |

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | var(--el-bg-color) | Background, surfaces |
| Secondary (30%) | var(--el-fill-color) | Cards, sidebar, nav background |
| Accent (10%) | var(--el-color-primary) | Primary buttons, active tabs, active table rows |
| Destructive | var(--el-color-danger) | Destructive table actions (delete, remove) |

Accent reserved for: Primary calls to action (New Document, Upload), active states.
